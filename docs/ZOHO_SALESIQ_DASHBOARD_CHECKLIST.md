# Zoho SalesIQ Dashboard Checklist

## Widget Installation
- Where: SalesIQ Admin > Installation / Widget
- Why: Required to load the live widget on the site.
- Mandatory: Yes

## Brand
- Where: SalesIQ Admin > Brands
- Why: Controls the widget appearance, pre-chat fields, and brand-level rules.
- Mandatory: Yes

## Operators
- Where: SalesIQ Admin > Operators
- Why: Required for live chat handoff and operator visibility.
- Mandatory: Yes

## Departments
- Where: SalesIQ Admin > Departments
- Why: Needed for routing and team assignment.
- Mandatory: Optional but recommended

## Routing Rules
- Where: SalesIQ Admin > Routing / Rules
- Why: Needed to direct chats to the right team.
- Mandatory: Optional but recommended

## CRM Integration
- Where: SalesIQ Admin > Integrations > CRM
- Why: Allows visitor data to sync into Zoho CRM if configured.
- Mandatory: Optional

## Visitor Fields
- Where: SalesIQ Admin > Settings > Visitor Fields
- Why: Ensures custom fields like Company, InterestedProduct, and Budget can be used.
- Mandatory: Optional

## Pre-chat Forms
- Where: SalesIQ Admin > Brands > Flow Controls
- Why: Controls required fields such as name, email, phone, and company.
- Mandatory: Recommended

## Widget Appearance
- Where: SalesIQ Admin > Brands > Widget Appearance
- Why: Ensures the widget looks and behaves correctly for your site.
- Mandatory: Recommended

## Working Hours
- Where: SalesIQ Admin > Working Hours
- Why: Lets SalesIQ show offline/online behavior correctly.
- Mandatory: Recommended

## Offline Messages
- Where: SalesIQ Admin > Offline Messages
- Why: Ensures visitors see a fallback when agents are unavailable.
- Mandatory: Recommended

## Audio/Video Calls
- Where: SalesIQ Admin > Settings / Features
- Why: Required only if you plan to use calling features.
- Mandatory: Optional

## Canned Responses
- Where: SalesIQ Admin > Canned Responses
- Why: Helps operators respond faster during live conversations.
- Mandatory: Optional

## Permissions
- Where: SalesIQ Admin > Permissions / Roles
- Why: Ensures the right team members can access chats and settings.
- Mandatory: Yes
